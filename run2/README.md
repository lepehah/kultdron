# run2 — быстрая панель и автозапуск

Это копия `запуск` с двумя изменениями: сайт грузится без Касперского и CDN, кнопка **Запуск полёта** сама копирует скрипты на дроны и стартует их.

## Почему старый сайт тормозил

В HTML были вшиты скрипты Kaspersky (скачали файл через браузер с антивирусом) и `roslib` с jsDelivr. Браузер ждал эти внешние URL, часто по таймауту. В run2 их нет: панель локальная, данные идут через `/api/...`.

## Один раз: SSH без пароля

Автозапуск работает только если с ноутбука можно зайти на платы без вопроса пароля:

```bash
ssh-copy-id sverk@192.168.1.19
ssh-copy-id sverk@192.168.1.27
ssh sverk@192.168.1.19 'echo ok'
ssh sverk@192.168.1.27 'echo ok'
```

## Как летать

1. `cd /home/lepehha/Загрузки/1234/run2`
2. `python3 ui_server.py` — окно не закрывать
3. Браузер: http://127.0.0.1:8080/
4. Нарисовать деление и старты
5. **Запуск полёта** — matrix уезжает на `.19` и `.27`, там стартует `a8gem.py`
6. **Стоп** — `pkill a8gem.py` на обоих

Скачивать matrix вручную и делать `push_mission.sh` больше не обязательно. Кнопка «Скачать» осталась на всякий случай.
