# kultdron — основной репозиторий Сверх.Рой

GitHub: https://github.com/lepehah/kultdron  
Рабочие папки: `kultdron/run2/` (связь/камера) и `kultdron/run3/` (первый полёт).

Старый репозиторий `lepehah/1234` больше не основной.

## Задача

Два дрона Сверх, поле ArUco 5×5, деление цветными листами (`-1`), поиск цветов, панель на ноутбуке.

## Запуск панели

```bash
cd ~/Загрузки/1234/kultdron/run2
python3 ui_server.py
```

Браузер: http://127.0.0.1:8080/

## Мост на дроне (орги)

На каждом дроне HTTP **:9090** — готовый мост к ROS. Координаты: сервис **get_telemetry** (как в Python `drone.control.get_telemetry`). Кнопка **Мост 9090**.

Камера для теста: карточка **Web video server** `http://IP:8080` (снимок `/snapshot?topic=/camera_1/image_raw`). Кнопка **Камера**.

Топики: **Топики** → `ros2 topic list` через `board_run.sh` (source ROS / docker), не голый `python3`.

## Почему 123.py падал

В логе:

```
FileNotFoundError: ros2
# раньше ещё: ModuleNotFoundError: ros2
```

1. `import ros2` — такого модуля Python нет. `ros2` — это **команда** в шелле.
2. `subprocess.run(["ros2", "topic", "list"])` с голого SSH `python3` не видит ROS: нет `source ~/sverk_ws/install/setup.bash`, команда не в PATH.

Нужно либо кнопка **Топики**, либо:

```bash
source /opt/ros/humble/setup.bash
source ~/sverk_ws/install/setup.bash
ros2 topic list
```

часто внутри контейнера `sverk_ros2`.
