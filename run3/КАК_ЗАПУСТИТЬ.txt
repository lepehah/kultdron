Проверка ARM (сначала это):

  scp arm_test.py sverk@IP:/home/sverk/mission/
  ssh sverk@IP
  source /opt/ros/humble/setup.bash
  source ~/sverk_ws/install/setup.bash
  python3 /home/sverk/mission/arm_test.py

В терминале должно быть armed=True. Если нет — offboard/ArUco/предохранитель, не «скрипт квадрата».

Один файл + карта, без сайта.

Правое поле (дрон 2): Right_TSU.txt  метки 25–49
Левое поле (дрон 1): Left_TSU.txt   метки 0–24

1. Скопируй скрипт и карту:

   scp square_flight.py Right_TSU.txt sverk@192.168.1.27:/home/sverk/mission/

2. SSH и ROS:

   ssh sverk@192.168.1.27
   source /opt/ros/humble/setup.bash
   source ~/sverk_ws/install/setup.bash
   python3 /home/sverk/mission/square_flight.py /home/sverk/mission/Right_TSU.txt

Если source не помогает:

   docker exec -it $(docker ps --format '{{.Names}}' | grep -i sverk | head -1) bash
   python3 /home/sverk/mission/square_flight.py

Маршрут: (0,0) → (4,0) → (4,4) → (0,4) → (0,0), в терминале печатает координаты и ID меток, садится.
