## Почему 123.py ошибка

Пользователь написал `subprocess.run(["ros2", "topic", "list"])`. SSH запускает системный python без ROS. `ros2` не в PATH → FileNotFoundError. `import ros2` тоже не работает: это CLI, не pip-пакет.
